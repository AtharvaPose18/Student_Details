# Student Information System
A simple Java program that accepts and displays the details of two students, including their names, roll numbers, and marks.

## Features
- Accepts details for two students
- Stores student information in separate objects
- Displays each student's details
- Uses a reusable method to display information

## Technologies Used
- Java
- Scanner class
- Classes and objects
- Instance variables
- Methods

## How to Run
1. Download Student.java.
2. Open a terminal in the folder containing the file.
3. Compile the program:
   javac Student.java
   
4. Run the program:
   java Student
   
## Concepts Practised
This project demonstrates basic Object-Oriented Programming concepts, including class creation, object instantiation, instance variables, methods, and user input.
